One sentence pitching NapTrack Pro, an AI app that detects the exact moment you fall asleep on the couch and wakes you up to tell you about it, entered for the make.fun bounty "The Worst App Idea Ever Pitched".

## Run it

```sh
python3 main.py
```

The program writes exactly one sentence (217 characters plus a trailing newline, 218 in total) to `/output/entry.txt` (falling back to `./output/entry.txt` if `/output` cannot be written).
